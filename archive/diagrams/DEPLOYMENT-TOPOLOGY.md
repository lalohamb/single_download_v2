## Deploy Script Flow (`scripts/deploy.sh`)

```mermaid
flowchart TD
  A([Developer: ssh into VPS]) --> B[cd /var/www/bodyandsleeves]
  B --> C{--skip-build flag?}

  C -- No --> D[git stash]
  D --> E[git pull origin main]
  E --> F[pm2 stop bodyandsleeves\n~165 MB freed]
  F --> G[npm install --prefer-offline]
  G --> H[npm run build\n600-900 MB peak]
  H --> I

  C -- Yes --> I[Copy assets to standalone\n.next/static, public, .env.local]

  I --> J[Generate ecosystem.config.js\nfrom .env.local via Node.js inline script]
  J --> K{PM2 process exists?}
  K -- Yes --> L[pm2 start --update-env]
  K -- No --> M[pm2 start]
  L --> N[pm2 save]
  M --> N

  N --> O{SUPABASE_ACCESS_TOKEN set?}
  O -- Yes --> P[supabase functions deploy\nstripe-checkout stripe-webhook\nprintify-proxy printify-webhook]
  P --> Q[Read stripe_mode from DB settings]
  Q --> R[Push STRIPE_SECRET_KEY +\nSTRIPE_WEBHOOK_SECRET to\nSupabase edge fn secrets]
  R --> S

  O -- No --> S[nginx -s reload]
  S --> T([Deploy complete])
```

## RAM Budget (1 vCPU / 2 GB Droplet)

| Phase | RAM Usage | Notes |
|---|---|---|
| Idle (app running) | ~165 MB | PM2 + Next.js standalone |
| During `npm run build` | 600–900 MB | TypeScript compile + webpack |
| Build + app running simultaneously | ~765–1065 MB | Risky on 2 GB — OOM possible |
| **deploy.sh strategy** | **stop app → build → restart** | ~30–60s downtime window |

## Zero-Downtime Alternative

`scripts/build-and-push.sh` builds locally and pushes the pre-built `.next/` to the server, avoiding the stop-build-restart cycle. Requires sufficient local RAM.

```
Local machine:
  npm run build
  rsync .next/ root@droplet:/var/www/bodyandsleeves/.next/
  ssh root@droplet "cd /var/www/bodyandsleeves && pm2 restart bodyandsleeves"
```
